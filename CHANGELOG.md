# Changelog

All notable changes to Trackfecta are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Organisation (workspace) switching. The app lists every organisation your
  account belongs to. The switcher is a dropdown in Settings, in the Account
  section. Each
  organisation keeps its own entries, projects, clients, tags, and sync
  cursor in the local cache. A running timer keeps running when you switch.

## [1.0.1] - 2026-10-11

Packaging fixes. No app-code changes.

### Fixed

- AppImage on Wayland: the bundler copied the build host's `libwayland-*`
  into the package, and the AppRun put that copy first on `LD_LIBRARY_PATH`.
  Two libwayland copies split the Wayland proxy registry, so the WebKit web
  process aborted with `EGL_BAD_PARAMETER` and no window appeared. The release
  workflow now excludes `libwayland-*` from the bundle
  (`LINUXDEPLOY_EXCLUDED_LIBRARIES`), so the app uses the host's Wayland.
- Snap launcher: the desktop entry now ships in `meta/gui/` (declared through
  the app's `desktop:` key). snapd registers only entries from there, so the
  installed snap had no launcher and the Store page had no Open button.
- Snap keyring guidance: the published revision predates the
  keyring-unreachable fallback and the AppArmor denial matcher. 1.0.1 has both.
- Deb/rpm/AppImage icon: the packages now install a full hicolor PNG ladder
  (16-512, generated by `scripts/render_logo.py`) next to the scalable SVG,
  and the mislabeled 256x256@2 slot (a 256px file in a 512px directory) is
  gone, so launchers never upscale a small bitmap.
- Snap Store security scan (USN-8910-1, libxml2): rebuilding refreshes the
  staged Ubuntu packages to the patched versions.

## [1.0.0] - 2026-10-01

First public release.

### Added

- Tray-first Toggl Track client for Linux built on Tauri v2 (Rust) with a
  Svelte 5 + Tailwind CSS v4 interface.
- Quick start/stop of time entries synced directly to the Toggl Track API v9,
  from both the window and the tray.
- Resume-last-entry from the tray menu, prefilled with the last description.
- Live tray status: the running entry while it ticks, today's total when idle.
- Background sync loop (10 s while running, 30 s idle, instant refresh on
  window focus) with rate-limit backoff that honors `429 + Retry-After`.
- API-token authentication validated against `GET /me`, stored in the OS
  keyring (no token on disk), with session restore on launch and graceful
  logout when a token is rejected.
- Daemon-like behavior: close-to-tray, single instance, autostart.
- Light, dark, and system themes via `prefers-color-scheme`.
- Release workflow builds `.deb`, `.rpm` and AppImage bundles for GitHub
  Releases (first published release coming soon).
